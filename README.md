# Software Engineering Interview Prep

A personal workspace for studying data structures, algorithms, and software engineering interview problems. It contains TypeScript practice files, problem-solving exercises, study notes, and reference material.

## Getting started

Install the project dependencies:

```sh
npm install
```

Run a TypeScript file directly with a recent version of Node.js that supports TypeScript type stripping:

```sh
node path/to/file.ts
```

Run a JavaScript file with:

```sh
node path/to/file.js
```

Check the TypeScript files for type errors:

```sh
npm run check
```
